# 任务完成检查清单

## 任务完成后应执行的步骤

### 代码质量检查
- **当前项目未发现自动化的代码质量工具配置**（如 flake8, pylint, black）
- 建议手动检查：
  - 代码格式和缩进一致性
  - 类型提示完整性
  - 文档字符串完整性

### 运行验证
- 确保脚本可以正常执行
- 检查输出目录和文件是否正确生成
- 验证日志文件是否正常记录

### 数据验证
- 检查中间数据文件的格式和完整性
- 验证模型训练是否收敛
- 检查评估指标是否合理

### 清理工作
- 清理临时文件（如有）
- 整理输出目录结构
- 更新必要的文档或 README（如果存在）

### 提交前检查（如果使用版本控制）
- 确认不需要提交的文件已添加到 .gitignore
- 检查是否有敏感信息（如 API 密钥）需要移除或替换
- 确认提交信息清晰描述更改内容

## 注意事項
- 项目使用 Windows 系统，注意路径分隔符
- 大文件输出（如图像、模型文件）通常保存在 `output/` 或 `result/` 目录
- 日志文件保存在 `logs/` 目录
- 配置文件可能包含敏感信息（API 密钥等），注意安全
